# 常见问题

## 保存后配置没有生效

多数配置保存后需要在顶部「搜索页面或动作」中选择「应用配置」，网卡方向、WAN 线路与安全流控保存后立即生效。应用结果可在「系统状态 → 最近应用」查看。

## 内网终端无法上网

按顺序检查：

1. WAN 线路是否在线（「概览」或「WAN 线路」）；
2. 是否存在默认上网策略：策略路由中源/目的留空、类型 NAT、出口选择 WAN；
3. LAN 线路地址与 DHCP 服务是否匹配；
4. 终端是否正确获取到地址、网关与 DNS；
5. 策略序号是否被更靠前的规则拦截。

没有匹配任何策略的流量不会出网，默认策略是必需的。

## 域名分流没有按预期走代理

1. 确认域名已加入「对象管理 → 域名组」，且该组已启用；
2. 确认策略的「目的域名组」选择了该组，且序号排在默认策略之前；
3. 修改后是否已「应用配置」；
4. 终端或本地 DNS 可能缓存了旧解析结果，可等待缓存过期或清理客户端缓存后重试。

## PPPoE 拨号失败

- 核对账号、密码与运营商是否需要特殊配置；
- 确认 WAN 线路绑定的网卡方向为 WAN；
- 在「WAN 线路」查看拨号状态与错误信息；
- 更换网线或光猫端口后重试。

## IPv6 无法获取地址

- 确认 WAN 线路支持 IPv6 并已获取前缀；
- 在「LAN 线路」打开「IPv6 前缀派发（来自 WAN）」；
- 终端需要开启 IPv6 并允许接收路由通告；
- 运营商前缀变化后设备会自动恢复，无需手工重启。

## 打不开管理页面

- 确认电脑连接的是**管理口**，而不是数据口；
- 确认地址与网段正确，访问的是 `https://`；
- 自签名证书提示属于正常现象，选择继续访问；
- 修改管理地址后请使用新地址登录，旧连接会中断。

## 忘记管理员密码

- 若从未修改过初始密码，可在设备上查看 `/root/ly-route-initial-admin-password`；
- 否则需要恢复出厂配置后重新初始化（会清除业务配置，请先备份）。

## 设备重启或升级后页面显示“系统重启中”

升级或应用过程中控制服务会重启，属正常现象；等待页面自动恢复即可。若长时间未恢复，可在「系统状态」查看组件健康。

## 网卡显示“兼容模式”或“待接管”

- **兼容模式**：该网卡使用兼容转发方式，功能完整但吞吐较低；
- **待接管**：系统正在自动处理，通常无需干预；
- 若长时间停留在异常状态，可重启设备后再次查看。

## 限速规则无法保存

设备会检测当前转发能力；能力未知或不可用时只允许创建阻断规则，限速规则会被拒绝。可在「安全流控」页面查看当前能力提示。

## 设备温度过高

设备内置温度保护：温度较高时会自动降低负载，过高时会拒绝高风险操作并在界面提示。请检查散热与风道，待温度恢复后再操作。

## 升级包上传后被拒绝

- 只接受 `.tar.zst` 或 `.zst` 格式的官方升级包；
- 校验失败通常表示文件不完整或与设备架构不匹配（x86-64 / ARM64）；
- 重新下载后再次上传，升级失败会自动回滚到升级前状态。

## 如何备份和恢复配置

- 「配置管理 → 导出配置」生成 JSON 备份；
- 「配置管理 → 快照」保存当前配置，可随时恢复；
- 导入配置后需要点击「应用配置」；
- 恢复出厂会清除业务配置，输入 `RESET` 确认后执行。
