# 使用手册

适用版本：**1.2**

本手册按控制台左侧菜单顺序编写。多数配置保存后需要在顶部「搜索页面或动作」（Ctrl/⌘ K）中选择「应用配置」才会下发到设备；网卡方向、WAN 线路与安全流控保存后立即应用，页面会给出对应提示。系统按本次改动范围增量下发，状态自动刷新。

---

## 1. 登录与界面

- 地址：`https://<管理地址>/`，使用自签名证书，浏览器提示后选择继续访问。
- 账号：管理员 `admin`（可另建只读账号）。
- 首次登录必须修改密码。

界面结构：

| 菜单 | 页面 | 用途 |
|---|---|---|
| 概览 | 总览 | 设备、WAN 出口、在线用户与流量趋势 |
| 监控 | 在线用户 / Top 连接 / Top 域名 | 终端、会话与域名查询排行 |
| 网络 | 网卡设置 / WAN 线路 / WAN 群组 / LAN 线路 / DHCP 服务 / 代理资源 | 接口与线路 |
| 策略 | 策略路由 / 端口映射 / DNS 策略 / 安全流控 / 对象管理 | 分流与访问控制 |
| 系统 | 系统状态 / 配置管理 / 固件升级 / 管理员账号 | 运维 |

顶部「搜索页面或动作」（Ctrl/⌘ K）提供「应用配置」与「刷新当前页面」；只读账号只能查看，不能修改。

## 2. 配置与应用

1. 新增或编辑配置，点击「保存」。
2. 页面提示“保存后需要应用配置”的（如 LAN 线路、策略路由、端口映射、DNS 策略、DHCP、配置管理），在顶部「搜索页面或动作」中选择「应用配置」。
3. 页面提示“保存后立即应用/生效”的（网卡方向、WAN 线路、安全流控），保存即下发。
4. 在「系统状态 → 最近应用」查看结果：
   - **配置已应用并收敛**：下发成功；
   - **配置未变化，已跳过**：本次没有需要下发的改动；
   - **应用失败**：查看失败原因，修正后重新应用。

保存写入的是期望配置；需要应用的配置在应用成功后才会改变转发。

## 3. 概览

展示系统健康、WAN 出口状态、在线用户数量、当前上下行速率、活动连接数与 WAN 流量趋势。可切换 5 分钟 / 1 小时 / 24 小时时间范围。

## 4. 在线用户

列出局域网内在线终端，包括 IP、MAC、主机名、在线时长、当前上下行与总流量、连接数。点击终端可查看其会话（源/目的/NAT 地址、状态）。

## 5. 网卡设置

用于查看物理网卡状态并设置接口方向。

- **接口方向**：管理口 / WAN / LAN / 未配置。方向只是接口属性，不会自动创建线路。
- **管理口**由系统保留，不能设为 WAN 或 LAN。
- **链路状态与接管状态**：已接管表示已由转发引擎处理；兼容模式表示可用但吞吐较低；待接管表示尚未完成，系统会自动继续处理。
- **聚合组**：把两张及以上同速率、已接管的网卡组成一个逻辑接口，供 WAN/LAN 线路引用。删除聚合组后成员网卡恢复为独立端口。

> 改变接口方向或删除聚合组会影响引用它的线路、DHCP 与策略配置，请先确认引用关系。

## 6. WAN 线路

WAN 线路是设备访问外网的出口，类型包括：

| 类型 | 说明 |
|---|---|
| PPPoE | 填写账号、密码，由设备拨号 |
| 静态 IP | 填写 IP/掩码、网关、DNS |
| DHCP | 由上游自动分配地址 |
| 代理线路 | 只创建逻辑出口，节点或节点组在「代理资源」中绑定 |

- 「网络 → WAN 线路 → 新增 WAN」创建。
- 线路保存后**立即参与**应用；PPPoE 线路可查看当前地址、连接数和收发流量。
- 只有创建了线路，策略路由与端口映射才能选择对应出口。

## 7. WAN 群组

把多条 WAN 线路组合使用，适用于多线负载或主备。

| 模式 | 说明 |
|---|---|
| 主备 | 指定主线路与备选线路，主线路不可用时切换 |
| 权重负载 | 按权重分配流量，权重合计必须为 100% |
| 五元组负载 | 按源/目的地址、端口与协议分配连接 |
| 最大下行空闲带宽 | 按各线路剩余下行带宽分配 |
| 最小连接数 | 优先分配给当前连接数较少的线路 |

群组成员来自已配置的 WAN 线路，至少需要两条。修改或删除群组会影响引用它的策略。

## 8. LAN 线路

LAN 线路定义内网网段与网关地址。

1. 先在「网卡设置」把接口方向设为 LAN。
2. 进入「网络 → LAN 线路 → 新增 LAN」。
3. 填写名称、LAN 网卡、IP/掩码、网关、DNS、MTU。
4. 如需 IPv6，打开「IPv6 前缀派发（来自 WAN）」并选择前缀来源 WAN。

同一 LAN 网卡可创建多条 LAN 线路用于不同网段。LAN 线路保存后需要应用。

## 9. DHCP 服务

为 LAN 接口下发地址。

- **服务**：名称、LAN 接口、子网、网关、DNS、租约时长（小时）。地址池由子网自动生成。
- **静态分配**：将终端 MAC 固定到指定 IP，适合打印机、服务器等设备。
- **租约**：查看当前已分配地址、到期时间与在线状态。

删除 DHCP 服务后，客户端将无法获取地址或固定地址。

## 10. 策略路由

策略路由决定流量从哪个出口发出，是分流的核心功能。

- **序号**：1–65535，数字越小越先匹配；保存后需要应用。
- **类型**：
  - **NAT**：做源地址转换，适合普通上网；
  - **路由**：三层转发，不做地址转换，适合专线互联。
- **匹配条件**：源地址、目的地址、目的域名组、协议（Any / TCP / UDP / ICMP）、源端口、目的端口。留空表示任意。
- **出口**：WAN 线路、WAN 群组或代理出口。
- **下一跳**：路由类型可选填。
- **全锥型 NAT**：NAT 类型下可开启，便于点对点通信。

> 没有匹配任何策略的流量不会出网。请至少配置一条默认上网策略（源/目的留空、类型 NAT、出口选择主 WAN）。

域名分流：在「对象管理 → 域名组」维护域名后，在策略的「目的域名组」中选择。域名解析结果会自动归入该策略对应的出口，无需手工维护 IP。

## 11. 端口映射

用于从外网访问内网服务。

- **端口映射**：名称、线路、外部地址（留空则使用线路地址）、外部端口、内网主机、内网端口、协议。
- **静态 NAT**：线路、外部地址、内网地址，仅支持 IPv4。

创建后外部端口会转发到内网主机；删除立即影响映射流量。

## 12. DNS 策略

DNS 策略决定域名由哪个解析器解析，以及是否允许解析。

### 12.1 解析上游

| 字段 | 说明 |
|---|---|
| 名称 | 便于识别的名称 |
| 地址 | 单个 IP，或 DoH 地址（`https://` / `h3://`） |
| Bootstrap DNS | DoH 地址需要填写，用于解析 DoH 域名 |
| 承载 WAN | 该解析器从哪条线路发出 |

### 12.2 上游组

把多个解析上游加入同一组，查询时并行请求并返回最快响应，用于提高解析可用性。

### 12.3 策略

- **默认策略**：匹配所有域名的解析行为。
- **按域名 / 域名组 / 源 IP**：按序号匹配，指定不同的解析线路。
- **动作**：
  - **解析**：使用指定上游或上游组；
  - **经代理出口解析**：通过代理出口访问解析器（适合需要走代理的域名）；
  - **拉黑**：明确拒绝该域名，不返回解析结果。
- 删除域名组或上游前，请先调整引用它的策略。

## 13. 安全流控

按规则限速或阻断流量。

| 字段 | 说明 |
|---|---|
| 序号 | 1–65535，越小越先匹配 |
| 方向 | 上行 / 下行 / 双向 |
| 动作 | 限速（Mbps）或阻断 |
| 协议 | Any / TCP / UDP / ICMP |
| 内 / 外地址 | 源地址与目的地址 |
| 内 / 外端口 | 源端口与目的端口 |

规则保存后立即生效。设备会显示当前转发能力：能力未知时只允许创建阻断规则，无法创建限速规则。

## 14. 代理资源

用于把指定流量通过代理节点发出。

1. 在「WAN 线路」新增一条**代理线路**，它只创建逻辑出口。
2. 进入「代理资源」，为出口绑定节点、节点组或订阅。
3. 在「策略路由」中把需要代理的流量指向该出口。

| 对象 | 说明 |
|---|---|
| 代理节点 | 节点 URI（如 `vless://...`）与备注 |
| 代理订阅 | 填写订阅 URL，可手动刷新 |
| 节点组 | 从节点或订阅中选择成员，可按最低延迟挑选，并限制参与负载的节点数 |

页面提供 Xray 运行状态与最近日志，可手动重启。

## 15. 对象管理

- **域名组**：维护一组域名，供策略路由与 DNS 策略引用。支持单条添加、文本批量添加与文件导入。
- **IP 组**：维护一组 IP 或网段，供策略引用。
- 组内成员可启用/停用；删除被引用的组会导致相关策略失效。

## 16. 系统状态

- **组件健康**：控制面与各服务当前状态。
- **配置预览**：只读预览，不会修改设备。
- **应用事务**：显示期望、已应用与当前数据面版本号（generation），以及本次应用结果。
- **最近应用**：应用结果与警告。

## 17. 配置管理

| 功能 | 说明 |
|---|---|
| 管理口 | 修改管理接口与地址；变更会中断当前连接，请准备好用新地址重新登录 |
| 配置依赖 | 查看对象之间的引用关系，删除被引用对象会被拒绝 |
| 导出 / 导入 | 导出为 JSON 备份，导入后需要应用；文件上限 10 MiB |
| 快照 | 保存当前配置，可随时恢复 |
| 配置初始化 | 恢复出厂配置，输入 `RESET` 确认 |

## 18. 固件升级

上传 `.tar.zst` / `.zst` 升级包，校验通过后安装。升级过程中控制服务会重启，页面显示“系统重启中”，完成后自动恢复；业务配置和管理地址保留。详见 [安装与升级](INSTALL.md)。

## 19. 管理员账号

- 支持**管理员**与**只读**两种角色；只读账号不能修改配置。
- `admin` 与当前登录账号不能删除。
- 密码至少 8 位，且不能包含用户名。

## 20. 常见配置示例

### 20.1 单线上网

1. WAN 线路：新增 PPPoE 或 DHCP 线路。
2. LAN 线路：设置内网地址，例如 `192.168.10.1/24`。
3. DHCP 服务：绑定该 LAN 接口。
4. 策略路由：新增策略，源/目的留空，类型 NAT，出口选择 WAN 线路。
5. 应用配置。

### 20.2 指定域名走代理

1. WAN 线路：新增代理线路。
2. 代理资源：为该出口绑定节点或订阅。
3. 对象管理：创建域名组并加入需要代理的域名。
4. 策略路由：新增策略，目的域名组选择该组，出口选择代理线路，序号放在默认上网策略之前。
5. 应用配置。

### 20.3 外网访问内网服务

1. 端口映射：选择线路，填写外部端口、内网主机与内网端口。
2. 应用配置。
3. 通过 `外部地址:外部端口` 访问内网服务。

### 20.4 限制某终端带宽

1. 安全流控：新增规则，内地址填写终端 IP，方向双向，动作限速并填写 Mbps。
2. 应用配置。
